# BodyScan 사용자 유입 플랜

사이트: https://ghengoy.github.io/bodyscan/ · 한 줄: **"30초 체형·자세 테스트 — 당신은 거북이? 운동선수?"**

핵심 유입 엔진은 **결과 카드 공유**다. 결과가 "당신은 거북이시군요 🐢"처럼 공유하고 싶은 형태이고, 카드와 공유 문구에 사이트 링크가 붙어 있어 본 사람이 바로 들어온다(바이럴 루프). 모든 채널은 이 루프에 사람을 "첫 투입"하는 역할이다.

## 0. 이미 사이트에 들어간 것 (코드)
- 공유 시트에 카드 PNG + 링크 + 문구("내 체형 테스트 결과: {캐릭터} — 너도 해봐!")
- 카드 하단 워터마크 "👉 나도 30초 체형 테스트: ghengoy.github.io/bodyscan"
- 데스크톱/미지원 브라우저용 "링크 복사" 버튼
- 카톡·인스타·X 미리보기(OG 이미지·제목·설명), 검색용 제목/설명/키워드, FAQ, sitemap/robots, JSON-LD
- GA4 이벤트: `measure_complete`(캐릭터별), `share`(방법), `product_click`(카테고리) — `.env`에 `VITE_GA_ID` 넣고 `npm run deploy`

## 1. 오늘 할 일 (계정만 있으면 10분, 무료)
| 할 일 | 방법 |

## 2. 첫 100명: 커뮤니티 (무료, 가장 효율 좋음)
재미·테스트형 콘텐츠가 잘 퍼지는 곳에 **결과 카드 스크린샷 + 한 줄 후기** 형식으로 올린다. 광고처럼 보이면 삭제되니 "해봤는데 거북이 나옴 ㅋㅋ" 톤.

- 에펨코리아(유머/건강), 더쿠(이슈), 클리앙(모두의공원), 블라인드(헬스/일상), 네이트판, 인스티즈
- 네이버 카페: 헬스/필라테스/자세교정/패션(디젤매니아 등) — 규칙 확인 후
- 디시 헬스갤/패션갤, 레딧 r/korea 는 보너스

**글 템플릿 (복붙용)**

## 3. 숏폼 (인스타 릴스 · 틱톡 · 유튜브 쇼츠)
15~20초, 세로, 자막 필수. 3개 포맷을 번갈아 올린다.

1. **리액션형**: 폰 세워두고 → 카운트다운 → "당신은 거북이시군요 🐢" 뜨는 순간 리액션. 자막: "30초 체형 테스트 결과 실화냐"
2. **커플/친구 비교형**: 두 명이 차례로 → 캐릭터 비교("운동선수 vs 거북이"). 댓글 유도: "너는 뭐 나옴?"
3. **정보형**: "거북목인지 30초 만에 확인하는 법" — 화면 녹화 + 결과 + "영상 저장 안 됨" 강조

캡션 끝: "링크는 프로필에 👉" + 해시태그 `#체형테스트 #거북목 #자세교정 #라운드숄더 #체형분석 #운동 #필라테스 #헬스`

## 4. 인플루언서/제휴 (빌린 채널)
- 필라테스·PT·물리치료사 인스타(팔로워 1~5만대 20명)에 DM: "무료 자세 테스트 도구 만들었어요, 수강생 상담 전 재미로 돌려보세요" — 금전 제안 없이 도구 제공. 쓰면 그들의 콘텐츠가 유입이 됨
- 패션 쇼핑몰/쿠팡 파트너스 활동하는 블로거: 체형별 옷 추천 결과 화면이 그들의 콘텐츠 소재

## 5. 유료 광고 (계정·예산 생기면)
테스트 예산 **일 1~2만원 × 7일**로 채널별 CPC/유입당 측정 완료율(GA `measure_complete`)을 비교한 뒤 되는 채널에 몰아준다.

| 채널 | 타겟 | 소재 |
|---|---|---|
| 메타(인스타 릴스/스토리) | 18~34, 관심사: 헬스·필라테스·패션·다이어트 | 숏폼 1·2번 그대로 |
| 틱톡 광고 | 18~29 | 숏폼 1번 |
| 네이버 검색광고 | 키워드: 거북목 테스트, 체형 테스트, 자세 분석, 라운드숄더 자가진단 | 제목: "30초 거북목 테스트 - 폰 카메라로 바로" |
| 구글 검색광고 | 동일 키워드 | 동일 |

**광고 카피 3종**
- A. "당신은 거북이? 운동선수? — 폰 카메라로 30초 체형 테스트"
- B. "거북목·라운드숄더·골반 기울기, 설치 없이 30초 만에 확인 (영상 저장 안 됨)"
- C. "체형별 어울리는 옷까지 알려주는 무료 자세 테스트"

랜딩은 시작 화면 그대로(버튼 1개). 전환 이벤트는 `measure_complete`.

## 6. 수익 연결
- AdSense: 승인 후 `VITE_ADSENSE_*` → 시작·결과 화면 배너 + 상품 없는 슬롯에 네이티브 광고
- 쿠팡 파트너스: `products.json`의 27개 링크를 파트너스 링크로 교체(추천 키워드별). 결과 화면에서 바로 클릭되는 구조라 전환율이 일반 배너보다 높다
- 측정 완료 1,000건당 공유 수·상품 클릭 수를 GA에서 보고 카드 문구/상품 순서를 조정
