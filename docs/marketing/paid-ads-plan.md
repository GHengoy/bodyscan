# BodyScan 유료 광고 플랜

사이트: https://bodyscan-iota.vercel.app/ · 기본 플랜: [launch-plan.md](launch-plan.md)
프레임워크: marketingskills `ads` 스킬(손익 계산 → 소재 중심 타겟팅 → 7일 테스트 → 20%씩 확장)

## 0. 결론 먼저

**광고비로 직접 돈을 벌 수는 없다.** 광고로 데려온 방문자 1명이 버는 돈보다 클릭 1번 값이 수십 배 비싸다(아래 계산). 그래서 유료 광고의 목적은 수익이 아니라 두 가지다.

1. **공유 루프에 사람을 넣는 마중물**: 결과 카드를 공유하면 친구가 들어온다. 광고로 온 1명이 0.5명을 더 데려오면 실제 유입은 2배가 된다.
2. **어떤 문구가 먹히는지 싸게 알아내기**: 광고 문구별 클릭률을 보고 이긴 문구를 시작 화면·공유 문구·커뮤니티 글에 그대로 쓴다.

그래서 예산은 **"테스트비"로 상한을 정해 놓고** 쓴다. 첫 테스트: **하루 1만원 × 7일 = 7만원.**

## 1. 손익 계산 (방문자 1명 기준, 추정치)

| 항목 | 추정 | 근거 |
|---|---|---|
| 애드센스 | 5~10원 | 국내 RPM 1천 회당 1~3천원 × 시작·결과 화면 광고 3~4개 |
| 쿠팡 파트너스 | 1~3원 | 상품 클릭 5% × 구매 5% × 객단가 3만원 × 수수료 3% |
| **합계** | **약 6~13원** | |
| 메타(인스타) 링크 클릭 | 300~800원 | 국내 B2C 평균 |
| 틱톡 클릭 | 100~300원 | 18~29 타겟 |
| 네이버 검색 클릭 | 70~300원 | "거북목 테스트" 등 틈새 키워드 |

→ 클릭당 손실 약 **100~800원**. 공유 계수 K(광고로 온 1명이 데려오는 사람 수)가 높을수록 실제 1명당 비용이 `CPC × (1 − K)`로 내려간다. K는 GA4에서 `share ÷ measure_complete × 공유 1건당 유입`으로 본다.

**판단 기준**: 7일 테스트 후 `측정 완료 1건당 비용`이 **500원 이하**이고 공유율이 **10% 이상**이면 확장할 가치가 있다. 아니면 유료는 접고 무료 채널(커뮤니티·숏폼)에 집중한다.

## 2. 채널 순서

| 순서 | 채널 | 이유 | 하루 예산 |
|---|---|---|---|
| 1 | **틱톡 광고** 또는 **메타(인스타 릴스)** | "당신은 거북이시군요" 같은 결과 화면이 숏폼 소재로 강함. 18~34 | 7천원 |
| 2 | **네이버 검색광고** | "거북목 테스트", "체형 테스트"를 직접 찾는 사람. 클릭이 쌈 | 3천원 |
| 보류 | 구글 검색 | 국내 검색 점유율이 낮고 키워드 양이 적음 | — |

틱톡과 메타 중 하나만 고른다(예산 7만원을 쪼개면 둘 다 학습이 안 된다). 숏폼 영상을 찍을 수 있으면 틱톡, 이미지만 있으면 메타.

## 3. 세팅 체크리스트

- [ ] 광고 계정 만들기: 틱톡 Ads Manager / 메타 광고관리자 / 네이버 검색광고(searchad.naver.com)
- [ ] 목표: **트래픽(링크 클릭)**. 픽셀은 달지 않는다. "영상 저장·전송 없음"이 핵심 신뢰 포인트라 추적 스크립트를 늘리지 않고, 전환은 GA4로 본다
- [ ] 타겟: **대한민국, 18~34세, 관심사 비움(넓게)**. 2026년 메타·틱톡은 관심사를 좁히는 것보다 소재가 사람을 고르게 두는 쪽이 효율이 좋다
- [ ] 노출 위치: 모바일만(측정이 폰 전용)
- [ ] 링크에 UTM 붙이기 (아래)
- [ ] GA4 퍼널 확인: `session_start` → `measure_start` → `measure_complete` → `share` / `product_click`

**UTM 링크 (복붙용)**
```
틱톡:   https://bodyscan-iota.vercel.app/?utm_source=tiktok&utm_medium=paid&utm_campaign=test1&utm_content=소재번호
메타:   https://bodyscan-iota.vercel.app/?utm_source=meta&utm_medium=paid&utm_campaign=test1&utm_content=소재번호
네이버: https://bodyscan-iota.vercel.app/?utm_source=naver&utm_medium=cpc&utm_campaign=test1&utm_term=키워드
```
`utm_content`에 소재 번호(A1, B2…)를 넣어야 GA4에서 어떤 소재가 측정 완료까지 이어졌는지 보인다.

## 4. 소재 (광고처럼 안 보이게)

원칙: 매끈한 광고 디자인보다 **실제 폰 화면 녹화·결과 캡처**가 이긴다. 소재는 많이(10개 이상), 싸게 만든다.

### 앵글 4개 × 변형

| # | 앵글 | 첫 줄(훅) | 화면 |
|---|---|---|---|
| A1 | 결과 공개 | "폰 세워두고 30초… 나 거북이래 🐢" | 결과 화면 녹화 |
| A2 | 결과 공개 | "운동선수 나올 줄 알았는데 펭귄 다리 🐧" | 결과 화면 |
| B1 | 자가진단 | "거북목 몇 도인지 30초 만에 재 봄" | 측면 측정 장면 → 각도 |
| B2 | 자가진단 | "라운드숄더인지 폰 카메라로 확인하는 법" | 측정 → 결과 |
| C1 | 비교 | "커플로 해봤는데 결과 차이 실화냐" | 두 결과 카드 나란히 |
| C2 | 비교 | "엄마 vs 나 자세 대결" | 두 결과 카드 |
| D1 | 안심 | "영상 저장 안 되는 체형 테스트(서버 없음)" | 네트워크 0건 표시 화면 |

### 직업·상황 키워드 변형 (한 단어만 바꿔 새 소재로)

이긴 소재 하나에 정체성 단어만 넣어 복제한다. 보는 사람에게는 "내 얘기"가 되고, 알고리즘에는 누구에게 보여줄지 힌트가 된다.

- "**직장인** 10명 중 7명이 거북목이래서 재 봄"
- "**개발자**인데 거북목 18도 나옴"
- "**수험생** 자세 30초 테스트"
- "**필라테스** 3개월 차 자세 점검"
- "**육아맘** 어깨 높이 차이 확인해 봄"

### 네이버 검색광고

| 키워드 | 제목(15자) | 설명(45자) |
|---|---|---|
| 거북목 테스트, 거북목 자가진단 | 30초 거북목 테스트 | 폰 카메라로 바로 측정. 앱 설치·영상 저장 없음, 맞춤 스트레칭까지 무료 |
| 체형 테스트, 체형 분석 | 무료 체형 분석 테스트 | 어깨·골반 비율로 체형 분석, 어울리는 옷 스타일 추천. 30초면 끝 |
| 라운드숄더 자가진단, 골반 틀어짐 자가진단 | 자세 자가진단 30초 | 라운드숄더·골반 기울기를 폰으로 확인하고 맞춤 스트레칭 받기 |

제외 키워드: 병원, 한의원, 치료, 수술, 도수치료(치료 목적 검색은 우리 서비스와 안 맞고 의료 광고 심의 소지).

**문구 주의**: "진단", "교정", "치료" 단어는 광고 제목에 쓰지 않는다(의료기기·의료광고로 오인 → 심사 반려 위험). "테스트", "확인", "자가 체크"를 쓴다.

## 5. 7일 테스트 운영

| 일 | 할 일 |
|---|---|
| 1 | 소재 6~8개로 시작(앵글 A·B·C·D 고루). 예산은 캠페인 단위로 두고 플랫폼이 소재별로 나누게 |
| 3 | 노출이 거의 안 간 소재 중 자신 있는 것 2개는 따로 묶어 다시 돌려 본다(첫 배분에서 놓친 승자가 나온다) |
| 1~7 | 예산·타겟 건드리지 않기(학습 리셋됨) |
| 7 | GA4에서 소재별(`utm_content`) **측정 완료 1건당 비용**, **공유율** 비교 |

**확장 규칙**
- 이긴 소재: 예산을 한 번에 **20%씩만** 올리고, 올린 뒤 3~5일 기다린다(30% 넘게 올리면 학습이 처음부터 다시 시작된다)
- 이긴 문구는 **시작 화면 제목과 공유 문구에도 그대로** 넣는다(광고에서 본 약속과 첫 화면 문구가 같으면 이탈이 준다)
- 매주 1시간 새 소재 3~5개 추가(같은 소재를 오래 돌리면 클릭률이 떨어진다)

**중단 규칙**: 7일·7만원 뒤 측정 완료 1건당 비용 1,000원 이상 + 공유율 5% 미만이면 유료 중단 → 무료 채널로.

## 6. GA4에서 볼 것

탐색 → 유입경로 탐색: `session_start` → `measure_start` → `measure_complete` → `share`, 측정기준 `세션 소스/매체`, `세션 수동 광고 콘텐츠`(= utm_content).

| 지표 | 계산 | 의미 |
|---|---|---|
| 시작률 | measure_start ÷ 세션 | 첫 화면이 광고 약속과 맞는지 |
| 완료율 | measure_complete ÷ measure_start | 카메라·측정 흐름에서 이탈 |
| 공유율 | share ÷ measure_complete | 바이럴 루프 강도 |
| 완료당 비용 | 광고비 ÷ measure_complete | 판단 기준 |
