# BodyScan 무료 유입 실행안 (유료·틱톡 제외)

사이트: https://bodyscan-iota.vercel.app/ · 가이드: https://bodyscan-iota.vercel.app/guide/

채널 4개: **검색(가이드 페이지)** · **커뮤니티** · **인스타 릴스 / 유튜브 쇼츠** · **인플루언서·강사 DM**

원칙: **만든 사람임을 밝힌다.** 일반 사용자인 척 올리는 글은 들키면 강퇴되고 신뢰도도 잃는다. "제가 만들었는데 피드백 부탁드려요"는 대부분 커뮤니티에서 오히려 반응이 좋다(무료, 가입 없음, 데이터 안 가져감이 확실한 경우).

## 1. 검색 (자동으로 쌓임)

- 가이드 7쪽: `/guide/`(목록) + 거북목 · 라운드숄더 · 골반 경사 · 짝어깨·골반 높이 · O/X다리 · 체형
- sitemap에 자동 포함. 배포 후 할 일:
  - [ ] 구글 서치 콘솔 → URL 검사 → 가이드 7개 "색인 생성 요청"
  - [ ] 네이버 서치어드바이저 → 웹 페이지 수집 → 가이드 7개 요청, 사이트맵 재제출
- 효과는 2~8주 뒤부터. 서치 콘솔 "실적"에서 어떤 검색어로 들어오는지 보고, 노출은 많은데 클릭이 적은 페이지는 제목을 고친다.

## 2. 커뮤니티 (첫 100명)

**올리기 전에 각 게시판 규칙(홍보 금지 여부)을 꼭 확인.** 홍보 금지인 곳은 "자유/질문" 게시판이 아니라 "홍보/자작" 게시판을 찾거나, 안 되면 올리지 않는다.

| 곳 | 게시판 | 각도 |
|---|---|---|
| 클리앙 | 새로운소식 / 사용기 | 개발 후기 + 개인정보(온디바이스) |
| 디시 프로그래밍갤 · 헬스갤 | 일반 | 만든 썰 / 거북목 결과 |
| 네이버 카페(자세교정·필라테스·홈트) | 자유/정보 | 거북목 가이드 + 테스트 |
| 블라인드 | 헬스·다이어트 / 개발 | 직장인 거북목 |
| 에펨코리아 | 유머/자유(규칙 확인) | 결과 캐릭터 재미 |
| 레딧 r/korea · r/SideProject | — | 영어, 만든 썰 |

## 3. 인스타 릴스 · 유튜브 쇼츠

세로 9:16, 15~25초, **자막 필수**(소리 끄고 보는 사람이 대부분). 같은 영상을 두 곳에 올린다.

### 대본 1 — 결과 공개 (가장 쉬움)
| 초 | 화면 | 자막 |
|---|---|---|
| 0–2 | 폰을 바닥에 세우는 손 | "폰 카메라로 30초 체형 테스트 해봄" |
| 2–8 | 뒤로 물러나 정면 → 옆으로 돌기(빨리감기) | "정면 3초, 옆으로 3초" |
| 8–14 | 결과 화면 "당신은 거북이시군요 🐢" 확대 | "…거북이래 🐢 18도" |
| 14–20 | 맞춤 스트레칭 펼치기 | "스트레칭까지 알려줌" |
| 20–24 | 결과 카드 | "너는 뭐 나와? 링크는 프로필" |

### 대본 2 — 비교 (댓글 유도)
"친구랑 체형 테스트 대결" → 두 사람 차례로 측정 → 결과 카드 둘 나란히 → "운동선수 vs 펭귄 다리 🐧" → "너는 누구랑 해볼래?"

### 대본 3 — 정보형 (검색·저장 유도)
"거북목인지 10초 만에 확인하는 법" → 벽 테스트 시연 → "정확한 각도는 폰으로" → 측면 측정 → 각도 → "저장해두고 한 달 뒤 다시 재보기"

- **캡션**: 첫 줄에 질문("거북목 몇 도 나와요?") + "링크는 프로필 👆"
- **해시태그**: `#거북목 #거북목테스트 #자세교정 #라운드숄더 #체형테스트 #체형분석 #홈트 #스트레칭 #직장인`
- **프로필 링크**: `https://bodyscan-iota.vercel.app/?utm_source=instagram&utm_medium=social` / 유튜브는 `utm_source=youtube`
- 주 2개. 조회수 높은 형식을 반복하고, 댓글로 나온 질문은 다음 영상 주제로.
